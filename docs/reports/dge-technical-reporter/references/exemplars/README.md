# Exemplar reports and reusable patterns

This folder contains two user-provided technical reports. Use them as structural and exposition examples, not as factual sources for a new repository unless that repository itself contains or cites them.

## RHOMOLO ESF+ report

File: `RHOMOLO_ESF_plus_report.pdf`

Useful patterns:

- An abstract that states the policy, model extension, shock channels, and directional findings.
- An executive summary that quantifies GDP, employment, labour force, multiplier, and disparity effects while separating findings from implications.
- A model section that identifies the spatial dynamic CGE structure, sectors, labour categories, wage setting, endogenous participation, baseline, and recursive dynamics.
- A policy-to-shock mapping table that distinguishes demand-side and supply-side effects.
- Explicit implementation timing and decay assumptions.
- Results reported as deviations from a no-policy baseline, with annual and cumulative measures clearly separated.
- Aggregate results followed by country heterogeneity, labour-market outcomes, and disparity indicators.
- A limitations paragraph that explains simplification, aggregation, shock translation, and parameter dependence.

## DGE-CRED Vietnam report

File: `DGE_CRED_Vietnam_report.pdf`

Useful patterns:

- A detailed table of contents separating model, calibration, scenarios, results, equations, steady state, elasticity estimation, and usage instructions.
- A model-structure diagram before the detailed equations.
- Economic blocks organized into climate variables, household demand, government, external finance, production, and resource constraints.
- Sector- and region-specific damage functions linked to physical climate variables.
- Calibration tables for elasticities, value-added shares, employment shares, trade, and regional allocations.
- Scenario construction that translates physical hazards and adaptation measures into productivity or capital effects.
- Extensive appendices for full equations, variable lists, calibration, steady-state computation, and repository usage.

## Combined reporting standard

For a new repository, combine the strengths of both examples:

1. Use the clear policy narrative, shock mapping, baseline-relative result reporting, and limitations discipline seen in the RHOMOLO report.
2. Use the detailed mathematical specification, calibration transparency, scenario engineering, and reproducibility appendices seen in the DGE-CRED report.
3. Do not copy wording, model assumptions, numerical values, or conclusions from either exemplar.
