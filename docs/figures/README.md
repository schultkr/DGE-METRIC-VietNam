# docs/figures/

Scenario-comparison figures generated by `scripts/reporting/*.m`. See
[`docs/reference/report_replication.md`](../reference/report_replication.md) for which script
writes which figure and which report cites it.

**Correct, current layout** (matches the scripts as of this repo's `RunSimulations.m`):
`docs/figures/EE_Simulation_Results/`, `docs/figures/Finance_Simulation_Results/`,
`docs/figures/EE_NZ_Simulation_Results/`, `docs/figures/NZ_Simulation_Results/`.

**Known-stale content — do not treat as current evidence:**
- `docs/figures/figures/EE_Simulation_Results/`, `.../Finance_Simulation_Results/`,
  `.../NZ_Simulation_Results/` — an accidentally double-nested copy from an older version of the
  reporting scripts (fixed upstream; the current scripts write one level up, at
  `docs/figures/<Name>/` directly). Also generated against an earlier scenario-naming generation
  (`EE_Directive10` etc. rather than `EE_Dir10_full`), so the content itself predates the current
  scenario set, not just the path. Superseded by a fresh run of `scripts/reporting/*.m`; kept for
  now rather than force-deleted (see `docs/reference/reproducibility_checklist.md` for what a
  fresh, dated run of these scripts should produce and record).
- `docs/figures/Finance_Simulation_Results_NZ/` — empty placeholder; the actual NZ green-finance
  figures (Macro Impact Assessment Figure 6) are produced by
  `scripts/reporting/generate_gf_nz_simulation_results_figures.m` (see its own `outDir`).

If you're regenerating figures for a report, run the scripts named in
`report_replication.md`, confirm the output lands directly under `docs/figures/<Name>/` (no
doubled segment), then remove the stale `docs/figures/figures/` tree and this note.
